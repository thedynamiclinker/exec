## New Human Shell

To use the standalone checkout in your current shell, run
`export PATH="$HOME/Desktop/yhwh/bin:$PATH"` and start it with `@`.

The fallback lives in this checkout. Put its `bin` on PATH and run `@.old`
to start the shell or `@.old REQUEST` for a single agent turn.
For example, `printf '@\n' | @.old ot` asks for the Old Testament name.
`@unix.old` runs the original Unix-filter profile. See `man lord.old` for
the runner and its options.

`nsh.old` tries lines in Bash and delegates failures to `law.old`. Answer a
clarifying question at the next prompt. A bare `@` between simple stages
such as `cat names @ sed 's/old/new/'` goes straight to the agent. Readline
supports editing, Tab completion and history search. Terminal history goes
to `$NSH_HOME/history`, with space-prefixed lines omitted. Use Ctrl+C to
cancel input or a question, `:paste` to enter multiple lines, or
`ld.so COMMAND` to run Bash directly with the terminal's original streams.
`nhs.old` uses `>>>` and collects a block after a line ending in a colon.

The [@ profile](etc/lord/AGENTS-@.md.old) defines the shell's vocabulary and how
it learns. The shell adds `~/.nsh/bin` to PATH and the agent keeps scoped
definitions in `~/.nsh/etc/nshrc`. Set `NSH_HOME` to use a separate prefix.
Use `#!/usr/bin/env LD.old` or `#!/usr/bin/env nsh-ld.old` to run an
English file with this checkout's interpreter.
