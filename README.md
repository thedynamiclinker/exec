## New Human Shell

Put this checkout's `bin` on PATH. Run `@` on a terminal to start the shell,
or run `@ REQUEST` for a single agent turn. For example, `printf '@\n' | @ ot`
asks for the Old Testament name. `@unix` runs the original Unix-filter profile.

`nsh` tries each line in Bash and delegates failures to `law`. Answer a
clarifying question at the next prompt. Use Ctrl+C to cancel a pending
question, `:paste` to enter multiple lines, or `ld.so COMMAND` to run Bash
directly with the terminal's original streams. `nhs` uses `>>>` and collects
a block after a line ending in a colon.

The [@ profile](etc/lord/AGENTS-@.md) defines the shell's vocabulary and how
it learns. The shell adds `~/.nsh/bin` to PATH and the agent keeps scoped
definitions in `~/.nsh/etc/nshrc`. Set `NSH_HOME` to use a separate prefix.
An English file with the shebang `#!/usr/bin/env nsh-ld` can be run as its
own agent program.
